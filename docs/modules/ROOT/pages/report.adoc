= Network Status report
:description: The list of every network and what is wrong with it.

Press *L* (by default) to open the Network Status report.
It lists every network FicstFluids runs, with what is wrong with each and where.

.Example of status report
image::status-report-liquid.png[Status report of a liquid network]

== Severities

[horizontal]
Problem:: Something isn't working now: a machine starved, a pump with no power on a line that needs it.
Warning:: Something may go wrong, or is wasting power. In some cases, a warning may be acceptable.
Note:: Worth knowing, not wrong: a machine on standby, an inlet a little below its desired pressure.

The *Hide healthy networks* checkbox hides networks with nothing worse than a Note.

== Reading it

The report has two primary sections, "Liquid" or "Gas", selected by clicking the button. Clicking the "Analyze" button re-runs the analysis of every network, liquid and gas, allowing you to see an update if desired. The "Hide healthy networks" checkbox does exactly what it says. Unchecking the box shows all networks.

=== Description and location

The report provides a general description of the network as well as its location relative to your position (the location is the center of the area the network's machines cover). Each of the machines listed in the network also have a location relative to your current position. Clicking on "Mark on map" places a diamond shaped marker on the map that has a pipeline icon for the fluid in this network. The button changes to "Remove marker", or you can select the marker on the map to remove it as you would a manually placed marker.

=== Findings

Each line in a network's list is one finding about one machine, pump, compressor, valve or run of pipes.
During a start-up many of them are expected; see xref:starting-up.adoc#_what_the_report_shows_during_start_up[What the report shows during start-up].

[cols="3,2,5"]
|===
| Finding | Severity | What it means

| "… It draws nothing."
| Problem; Warning if the machine isn't running
| The inlet is at or below the pressure the machine needs to draw at all.

| "… is starved … It can run at only N%."
| Problem
| The machine has stopped crafting for lack of this fluid, and its inlet is below its full-speed pressure.

| "… Once its buffer is empty it will run at N%."
| Warning
| The inlet is below full-speed pressure, but the machine is still living off its buffer.

| "… its buffer refills more slowly …"
| Note
| The inlet is between full-speed and desired pressure. The machine runs at its full rate.

| "… can't deliver" / "… is idle"
| Problem while machines are short; Warning otherwise
| A machine outlet or extractor has something to give, but the pressure beside it is above what it pushes, so something stronger holds it shut.

| "A run of N pipes is X% full."
| Warning (liquid only)
| Those pipes aren't full.

| "… is running but moving nothing …"
| Warning
| A powered pump or compressor moves nothing and still uses power.

| "… is at its pressure ratio limit …"
| Warning (gas only)
| The compressor can't raise the pressure any further, so it pumps nothing.

| "… so it passes less."
| Warning (gas only)
| The compressor is unloading (shown as "relieving").

| "… stands fully open … below its setpoint …"
| Warning, only while machines are short
| The supply behind the valve delivers less than its limit.

| "… is on standby …"
| Note
| The machine has power but is switched off.

| A pump or compressor "has no power"
| Problem while machines are short; Warning otherwise
| A pump adds no pressure; a compressor passes no gas.

| A machine "has no power"
| Warning
| It neither takes from the network nor gives to it.
|===

=== The same pressure, different severities

The pressure says what a machine _will_ do; the severity says what it is doing now.

* A machine that has stopped crafting and holds less than one craft's worth is *starved*: a Problem ("can run at only N%").
* One still crafting, or still holding enough, is a Warning ("once its buffer is empty it will run at N%").
It is living off its buffer and will slow when that runs out.

So two machines side by side at 4.2 m and 4.3 m can show a Problem and a Warning.

=== Machines on standby warn about their pumps

On a line whose machines are all on standby, each machine gets a Note and each powered pump or compressor gets a Warning: it moves nothing while still using power.
That is expected.
To clear it, switch the machines back on, or turn the pumps off too.

=== Full speed and desired pressure

The report warns about an inlet below its machine's full-speed pressure and says what speed it will drop to.
An inlet between full speed and desired only gets a Note.
See xref:machines.adoc#_full_speed_comes_before_the_desired_pressure[Machines].

=== Pumps and compressors

A powered pump or compressor moving nothing is a Warning.
So is a compressor at its ratio limit, or unloading (shown as "relieving").
